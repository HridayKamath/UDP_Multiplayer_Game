Topology (live)

Dashed red link = client blocked by a priority-300 drop rule. The switch→server link is the bottleneck where the OVS HTB queues (0 = best effort, 1 = game) apply.

Dynamic SDN controls

Traffic prioritisation (QoS)
Game traffic → priority queue 1. Off = same queue as background (baseline).
Block / unblock a client
Installs a priority-300 drop rule for the host's game traffic. Use the buttons in the player table.
Auto-guard
If a player sends more than the limit updates/s, the server's measurement makes the controller block it (application event → SDN reaction).
